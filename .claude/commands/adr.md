Delegate to the arb-chair agent for ADR-$ARGUMENTS:

1. Read ADRs/$ARGUMENTS-*.md and spike/RESULTS.md.
2. Round-table: present each option as its best advocate would, one paragraph
   each, grounded only in evidence that exists (measurements, licence text,
   gate results). Flag every decision driver still lacking evidence.
3. Chair's draft recommendation with the single decisive driver named.
4. End with: "Decision remains with the maintainer. To close: edit the
   Decision section and set Status: Accepted."
Never edit the ADR's Decision section yourself.
